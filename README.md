# Zhambyl Gid

Жамбыл ауданы бойынша саяхатшыларға арналған жол көрсеткіш — қосымшаның веб-демо нұсқасы.

- `index.html` — барлық экрандар (бастапқы бет, басты бет, карта, орын туралы, қызметтер, профиль)
- `images/` — суреттер (Figma-дан экспортталған суреттерді осы папкаға саламыз)

Сайт: https://zhambyl-gid.vercel.app
